# Machine Learning Models Directory

This directory is reserved for Phase 5 AI/ML modules:
1. **Random Forest Classifier**: PC Health Status Prediction (`Healthy`, `Warning`, `Critical`)
2. **K-Means Clustering**: Lab Utilization Analysis (`Low`, `Medium`, `High`)
3. **TF-IDF + Decision Tree**: Complaint Priority Scoring (`Low`, `Medium`, `High`)

Contains model training scripts, evaluation metrics, and serialized `.joblib` model artifacts.
